Рабочая папка - папка, в которой происходит работа над проектом
Индекс - подготовка файла к отправке, которое появляется после git add
Коммит - зафиксированное изменение
Git - используется для отслеживаний изменений в коде
GitHub - сервис для хранения проектов
Использованные команды
git status - показывает изменения добавленные для коммита
git diff - показывает изменения 
git diff --staged - список фалов, подотовленных для сохранения
